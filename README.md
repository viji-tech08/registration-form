
# Registration Form Validation

A simple and responsive Registration Form built using HTML, CSS, and JavaScript. This project validates user inputs in real time and enables the Register button only when all fields are valid.

## About the Project

The Registration Form allows users to enter their Name, Email Address, and Password. JavaScript is used to validate the input fields and display error messages when the entered details are incorrect.

This project was created as a practice project to learn form validation and JavaScript DOM manipulation.

## Features

- Simple and user-friendly registration form
- Name field validation
- Email format validation
- Password minimum length validation
- Real-time error messages
- Submit button disabled until all fields are valid
- Success message after form submission
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Validation Rules

### 1. Name Validation
- The Name field must not be empty.
- An error message is displayed if the field is empty.

### 2. Email Validation
- The Email field must contain a valid email format.
- An error message is displayed if the format is incorrect.

### 3. Password Validation
- The Password must contain at least 6 characters.
- An error message is displayed if the password is too short.

### 4. Submit Button Validation
- The Register button remains disabled until all fields are valid.
- The button becomes enabled when all validation rules are satisfied.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file using the Live Server extension, or open it directly in a web browser.
4. Enter your Name, Email Address, and Password.
5. Check the validation messages and submit the form when all fields are valid.
